# Amazon Clone: Repository Summary

**Repository:** https://github.com/Abhinavkr004/Amazon-clone
**Author:** Abhinav Kumar

---

## Overview

A frontend clone of the Amazon homepage, built with plain **HTML and CSS** (no frameworks). It recreates the look and layout of Amazon's landing page for learning and practice. The README states it is for educational purposes only and is not affiliated with Amazon.

The GitHub "About" description calls it a responsive clone with reusable UI components and a user-friendly shopping interface.

---

## Features

- Amazon-inspired homepage layout
- Navigation bar with logo and search bar UI
- Location/address section
- "Account & Lists" section
- Shopping cart section
- Hero banner
- Multiple product/category boxes
- Footer-style sections
- Lightweight, with no external frameworks

---

## Tech Stack

| Technology | Used for |
|------------|----------|
| **HTML5** | Page structure and content |
| **CSS3** | Styling, Flexbox layout, navbar, product cards, hero section, spacing, colors, typography |

## How to Run

There is no build step. Clone the repo and open the main page in a browser:

```bash
git clone https://github.com/Abhinavkr004/Amazon-clone.git
cd Amazon-clone
# open clone.html in your browser
```
