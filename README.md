# 🛒 Amazon Clone

A frontend **Amazon Clone** website built using **HTML and CSS**.  
This project recreates the design and layout of the Amazon homepage, including the navigation bar, hero section, product/category boxes, and footer-style sections.

> ⚠️ This project is created for educational and practice purposes only. It is not affiliated with or endorsed by Amazon.

## 📌 About The Project

This Amazon Clone is a frontend project developed to practice and improve my skills in **HTML and CSS**.

The website is inspired by the Amazon homepage and focuses on recreating its:

- Navigation bar
- Amazon logo
- Search bar
- Hero/banner section
- Product/category cards
- Shopping sections
- Responsive layout
- Overall Amazon-inspired UI

The project uses locally stored images and CSS styling to create the interface.
